# feynman-reading 🧠

一个 AI Agent 用的阅读 skill：**费曼-芒格超级阅读法 (Feynman-Munger Cognitive Reading)**。
A reading skill for AI agents: **Feynman-Munger Cognitive Reading**.

融合费曼的"降维解释"、《认知天性》的"合意困难与生成效应"、查理·芒格的"多元思维模型网格"，把单薄的书本知识转化为深植大脑的跨学科智慧网络。
Fuses Feynman's "explain it simply," the "desirable difficulties & generation effect" of *Make It Stick*, and Charlie Munger's "latticework of mental models" — turning thin book knowledge into a cross-disciplinary wisdom network rooted deep in the brain.

## 怎么用 / Usage

把本仓库的 `SKILL.md` 放到你的 AI 助手 / Agent 的 skills 目录即可，例如：
Drop this repo's `SKILL.md` into your AI assistant / agent's skills directory, e.g.:

```
~/.skills/feynman-reading/SKILL.md
```

或 / or

```
~/workspace/skills/feynman-reading/SKILL.md
```

之后当你要求"用费曼学习法讲透某本书"时，助手会自动按 skill 里的五步流程执行：
Then, when you ask to "explain a book to the bone with the Feynman method," the assistant follows the skill's five-step flow automatically:

1. **逆向提问破冰 / Counter-intuitive ice-breaker** — 反常识问题先行，激发"生成效应" / Lead with counter-intuitive questions to trigger the generation effect
2. **核心概念拆解 × 多元思维模型 / Concept breakdown × mental models** — 每个概念挂钩一个芒格模型 + 逆向思考 + 生活短故事 / Each concept maps to a Munger model, plus inversion and a true-to-life story
3. **合意困难检索测试 / Desirable-difficulty retrieval test** — 带陷阱的情境应用题，强迫大脑费力提取 / Scenario questions with traps that force effortful retrieval
4. **认知冗余备份 / Cognitive redundancy backup** — 播客/TED/知识图谱等多感官备份 / Multi-sensory backup: podcasts, TED talks, knowledge maps
5. **多元模型交响曲 / Symphony of models** — 把全书概念编织进一个情境长故事，结局顿悟 / Weave every concept into one long situational story with a closing epiphany

**语言 / Language**：默认中文讲解，可随时要求切换英文；术语保持中英对照。
Explains in Chinese by default; switch to English anytime — terms always shown bilingually.
