# feynman-reading 🧠

一个 AI Agent 用的阅读 skill：**费曼-芒格超级阅读法 v2.0 (Feynman-Munger Cognitive Reading)**。
A reading skill for AI agents: **Feynman-Munger Cognitive Reading v2.0**.

> 让大脑毫不费力地吃透一本书。
> Make mastering a book feel effortless for the brain.

## 它是什么 / What it is

融合四套思想体系的深度阅读方法论：
A deep-reading methodology fusing four systems:

- **费曼学习法 Feynman Technique** — 降维解释，一页讲清
- **芒格多元思维模型 Munger's Latticework** — 每个概念挂钩一个底层模型 + 逆向思考
- **《认知天性》 Make It Stick** — 生成效应、合意困难、主动检索、间隔重复
- **《思考，快与慢》 Thinking, Fast and Slow** — 按大脑的运作模式设计内容流：System 1 先被故事吸引，System 2 再被测试激活

## 三大核心功能 / Three Core Functions

1. **全书结构与精髓总览** — 一句话灵魂、全书地图、核心论点、作者的思维底牌
   **Book overview** — one-line soul, full-book map, core theses, the author's thinking playbook
2. **全概念逐个故事化** — 书中所有概念，一个不漏，每个编成短故事/寓言，潜移默化掌握
   **Story-per-concept** — every concept in the book becomes a short story or fable; absorb them without noticing
3. **整书长篇故事整合** — 全部概念编织成一个有反转的长篇叙事，结局顿悟
   **One grand story** — all concepts woven into a single long narrative with a closing epiphany

## 呈现方式 / Presentation

- **图文并茂**：核心概念配示意图/信息图
- **多媒体**：播客、TED、纪录片、作者访谈推荐（附超链接与观看指引）
- **音频/视频/图片/超链接**：全部内嵌，可直接点击
- **分级检索测试**：L1 再认 → L2 回忆 → L3 迁移，附掌握度报告与复习计划

- **Rich visuals**: diagrams/infographics for core concepts
- **Multimedia**: podcasts, TED talks, documentaries, author interviews (with hyperlinks & viewing guides)
- **Audio / video / images / hyperlinks**: all embedded and clickable
- **Leveled retrieval tests**: L1 recognition → L2 recall → L3 transfer, with mastery report & spaced-repetition plan

## 怎么用 / Usage

把 `SKILL.md` 放到你的 AI 助手 / Agent 的 skills 目录：
Drop `SKILL.md` into your AI assistant / agent's skills directory:

```
~/.skills/feynman-reading/SKILL.md
```

然后说："用费曼学习法讲透《XXX》"。默认中文，可随时要求切换英文。
Then say: "用费曼学习法讲透《XXX》" (Explain book XXX to the bone with the Feynman method). Chinese by default; switch to English anytime.
